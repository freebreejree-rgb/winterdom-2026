# Winterdom 2026

Сайт-запрошення українською мовою з анімованими 3D-атракціонами.

Статичний сайт без збірки: HTML, CSS, JavaScript, локальна Three.js (MIT).
Усі файли готові для розміщення в корені репозиторію GitHub Pages.

## Публікація

1. Завантажити вміст цієї папки у публічний репозиторій.
2. Відкрити Settings → Pages.
3. Source: Deploy from a branch; Branch: main; Folder: / (root).
4. Зберегти та дочекатися успішного розгортання Pages.

Паролі, сервер і додаткові залежності для перегляду не потрібні.
